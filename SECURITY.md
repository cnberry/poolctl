# Security policy

`poolctl` can operate physical pool equipment. Report vulnerabilities privately
through GitHub's security-advisory feature instead of opening a public issue
with site topology, adapter addresses, raw payloads, or exploit details.

Never include real adapter names, local IPs, network captures, credentials from
adjacent systems, or private automation configuration in a report.

This project uses an unofficial local integration and cannot provide safety,
availability, or security guarantees for ScreenLogic or connected equipment.
